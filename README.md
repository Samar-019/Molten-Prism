# Molten Prism 🌊💎

> **Liquid Glass Client & Ambient Soundscapes for YouTube Music**  
> Creating immersive soundscapes that blend innovation, emotion, and fluid physics. From cinematic molten atmospheres to prism-tuned frequencies, experience audio reimagined.

---

## ✨ Features

- 💧 **Ultra-Fluid Liquid Glass UI**: Modern frosted glass aesthetics (`backdrop-filter`, refraction highlights, specular caustic glows, and dynamic blur).
- 🌈 **Prismatic Refraction Modes**: Toggle chromatic aberration and prismatic themes in real time.
- 🎶 **Interactive Soundscape Deck**: Real-time waveform visualizer, fluid playback deck, scrubber, and ambient sound channels.
- 🎛️ **Binaural Liquid Synthesizer Pad**: Interactive Web Audio API node generating procedural harmonic frequencies on cursor movement & click ripples.
- 📱 **Responsive & Adaptive**: Fully optimized for mobile, desktop, and tablet displays.
- 🚀 **Zero Dependencies**: Pure HTML5, CSS3, and Vanilla JavaScript with Web Audio API.

---

## 🚀 Quick Start & Local Preview

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/Samar-019/Molten-Prism.git
cd Molten-Prism
# Open index.html directly or serve with any static server:
npx serve .
```
